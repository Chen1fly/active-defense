# 人工把关清单（只给你自己看，不给 agent）

## 每天（约 15 分钟）
- 读四个 status 文件的“已知问题”和“待人决定”，逐条回复或决定
- 合并已完成的分支前，看一眼改动是否越出该角色的代码归属

## 必须亲自目视确认的关口（未通过不放行下一步）
1. ada 贴合检查图：纯色块是否准确贴在广告板上
2. ada contact sheet：行人和广告板在网格里的可见性是否合理；行人不可见的视角是否过多
3. a100 单元测试：选项 token 正确、两次查询 logits 逐位一致
4. h200 等价性测试：可微预处理与标准预处理的 logit 差 < 1e-2
5. clean 准确率热力图：10–25 米区间内是否大部分答对
6. A0、A1 在 nominal_set 上的攻击成功率是否达到 70% 左右

## 可能需要你做的决定（提前心里有数）
- 1m x 1m 广告板在 15 米处只占约 45 像素宽（VLM 输入尺度），攻击可能偏弱；是否放大
- 某些视角行人出画导致有效视角过少时，是否调整网格范围
- A1 达不到 70% 时，是缩小 EOT 范围、加大 patch，还是接受较低成功率
以上任何一项都带着数据来找导师讨论，不要让 agent 自行决定。

- clean 准确率热力图
- A0、A1 攻击成功率热力图
- h1.py 三项输出（可恢复比例曲线、异质性、按 panel 可见面积分桶的结果）
